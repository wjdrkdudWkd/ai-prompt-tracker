What is this?

AI Prompt Tracker automatically monitors your AI API calls when you use the @AIPrompt annotation.

API Endpoints:

  • /aiprompt-tracker/api/dashboard/summary
  • /aiprompt-tracker/api/functions
  • /aiprompt-tracker/api/executions
  • /aiprompt-tracker/api/calls

Configuration:

To enable persistence and see data in the dashboard, add to your application.yml:

ai-prompts:
  tracking:
    demo:
      enabled: true  # H2 + auto-migrate
